# Dynamo 主页的图形缩略图

Dynamo 主页将在宽卡上显示图形缩略图。该卡片是 16:9。主页将图像居中放置，并裁剪顶部和底部。

在衍生式设计中，方形缩略图看起来很完整，它显示了整个方形。同一个图像可能会丢失主页中的标题或徽标。

这适用于任何图形 (`.dyn`)，而不仅仅是软件包内的图形。在“图形属性”中设置图像。图像存储在图形文件中。

{% hint style="info" %}
将标题、徽标和主图像保留在中心**安全区域**。仅将方形缩略图的顶部和底部用作背景。
{% endhint %}

## 缩略图模板

下载模板并在其上进行设计。较暗的中心带是主页显示的。顶部和底部的较浅色带在主页中被裁剪。衍生式设计显示整个正方形。

> 下载 SVG 模板以在矢量应用程序中进行编辑，或下载 PNG 模板以将艺术作品放置在图像编辑器中。

## 构成缩略图

1. 在图像编辑器中打开 SVG 或 PNG 模板。
2. 将您的作品放在模板中的粉红色方块上。
3. 将标题、徽标和主图片保留在较暗的中心带内。
4. 仅将较浅的顶部和底部带用于背景色或额外的作品。
5. 隐藏或删除粉色导向，然后导出**方形** PNG。

使用**方形**图像 (1:1)。主页始终将较暗的中心带显示为 16:9 的裁剪。像素大小不会更改裁剪。如果您从空白文件而不是模板开始，请将其设置为方形。缩略图模板本身为 840 × 840 像素。

## 将缩略图添加到图形

主页从图形文件 (`.dyn`) 中读取缩略图，而不是从 Package Manager 发布表单中读取缩略图。

1. 在 Dynamo 中打开图形。
2. 转到**“文件”>“显示图形属性”>“常规”**。
3. 在图像字段中添加导出的 PNG。
4. 保存图形。

如果图形随附在软件包中，请在发布时包含该 `.dyn`。请参见[发布软件包](../6_custom_nodes_and_packages/6-2_packages/4-publishing.md)。

## 在主页中查看结果

1. 打开 Dynamo 主页。
2. 在“最近使用”下，找到您刚刚保存的图形。
3. 确认标题和徽标在卡片上完全可见。

如果文本被截断，请将其移向中心，再次导出图像，然后更新“图形属性”。不要仅仅依赖衍生式设计。衍生式设计显示整个正方形。
