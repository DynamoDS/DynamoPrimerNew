# Dynamo ホームのグラフ サムネイル

Dynamo ホームでは、グラフのサムネイルを横長のカードで表示します。カードは 16:9 です。ホームでは画像が中央に配置され、上下がトリミングされます。

正方形全体が表示されるジェネレーティブ デザインでは、正方形のサムネイル全体が表示されます。同じ画像でも、ホームではタイトルやロゴが見切れる可能性があります。

これは、パッケージ内のグラフに限らず、すべてのグラフ(`.dyn`)に適用されます。[グラフ プロパティ]で画像を設定します。画像はグラフ ファイルに保存されます。

{% hint style="info" %}
タイトル、ロゴ、メイン画像は、中央の**安全領域**内に配置してください。正方形のサムネイルの上下部分は、背景としてのみ使用してください。
{% endhint %}

## サムネイルのテンプレート

テンプレートをダウンロードし、その上にデザインを作成します。中央の色が暗い帯状の領域が、ホームで表示される部分です。上下の色が明るい帯状の領域は、ホームではトリミングされます。ジェネレーティブ デザインでは、正方形全体が表示されます。

> ベクター アプリで編集する場合は SVG テンプレートを、画像エディタでアートワークを配置する場合は PNG テンプレートをダウンロードしてください。

## サムネイルを作成する

1. SVG または PNG テンプレートを画像エディタで開きます。
2. テンプレート内のピンクの正方形にアートワークを配置します。
3. タイトル、ロゴ、メイン画像は、中央の色が濃い帯状の領域に配置します。
4. 上下の色が明るい帯状の領域は、背景色や追加のアートワークを配置する場合に限り使用します。
5. ピンク色のガイドを非表示または削除してから、**正方形**の PNG として書き出します。

**正方形**の画像(1:1)を使用してください。ホームでは、中央の色が濃い帯状領域が表示範囲となり、16:9 で表示されます。ピクセル サイズを変更しても、トリミング範囲は変わりません。テンプレートを使わず空のファイルから作成する場合は、正方形にしてください。サムネイル テンプレート自体のサイズは 840 × 840 ピクセルです。

## グラフにサムネイルを追加する

ホームは、Package Manager のパブリッシュ フォームからではなく、グラフ ファイル(`.dyn`)からサムネイルを読み込みます。

1. Dynamo でグラフを開きます。
2. **[ファイル] > [グラフ プロパティを表示] > [一般]**に移動します。
3. 画像フィールド、書き出した PNG 画像を追加します。
4. グラフを保存します。

グラフをパッケージに含めて配布する場合は、パブリッシュ時にその `.dyn` を含めてください。「[パッケージをパブリッシュする](../6_custom_nodes_and_packages/6-2_packages/4-publishing.md)」を参照してください。

## ホームで表示結果を確認する

1. Dynamo ホームを開きます。
2. [最近使用したファイル]から、先ほど保存したグラフを探します。
3. カード上にタイトルとロゴ全体が表示されていることを確認します。

文字が途切れている場合は、中央に向かって移動させ、もう一度画像を書き出してから、[グラフ プロパティ]を更新します。ジェネレーティブ デザインの表示だけで判断しないでください。ジェネレーティブ デザインでは、正方形全体が表示されます。
