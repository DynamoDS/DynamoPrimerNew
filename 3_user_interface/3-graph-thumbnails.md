# Dynamo 홈의 그래프 썸네일

Dynamo 홈에서는 가로로 긴 카드에 그래프 썸네일이 표시됩니다. 카드의 가로세로 비율은 16:9입니다. 홈에서는 이미지의 중앙을 기준으로 표시하고 위아래를 잘라 냅니다.

제너레이티브 디자인에서는 정사각형 썸네일 전체를 표시하므로 정사각형 이미지가 온전히 보일 수 있습니다. 하지만 같은 이미지를 홈에서 사용하면 제목이나 로고가 잘릴 수 있습니다.

이 내용은 패키지에 포함된 그래프뿐 아니라 모든 그래프(`.dyn`)에 적용됩니다. 그래프 특성에서 이미지를 설정하십시오. 이미지는 그래프 파일에 저장됩니다.

{% hint style="info" %}
제목, 로고 및 주요 이미지는 중앙의 **안전 영역** 안에 배치하십시오. 정사각형 썸네일의 위쪽과 아래쪽은 배경으로만 사용하십시오.
{% endhint %}

## 썸네일 템플릿

템플릿을 다운로드한 다음, 그 위에 디자인을 추가하십시오. 중앙의 어두운 영역이 홈에 표시되는 부분입니다. 위쪽과 아래쪽의 밝은 영역은 홈에서 잘려 나갑니다. 제너레이티브 디자인에서는 정사각형 전체가 표시됩니다.

## 썸네일 구성

1. 이미지 편집기에서 SVG 또는 PNG 템플릿을 엽니다.
2. 템플릿의 분홍색 정사각형 위에 아트워크를 배치합니다.
3. 제목, 로고 및 주요 이미지를 중앙의 어두운 영역 안에 배치합니다.
4. 위쪽과 아래쪽의 밝은 영역은 배경색이나 추가 아트워크에만 사용합니다.
5. 분홍색 안내선을 숨기거나 삭제한 다음 **정사각형** PNG를 내보냅니다.

**정사각형** 이미지(1:1)를 사용하십시오. 홈에서는 항상 중앙의 어두운 영역을 16:9 비율로 잘라 표시합니다. 픽셀 크기는 잘리는 영역에 영향을 주지 않습니다. 템플릿 대신 빈 파일에서 시작하는 경우 정사각형으로 만드십시오. 썸네일 템플릿 자체의 크기는 840 × 840픽셀입니다.

## 그래프에 썸네일 추가

홈에서는 패키지 관리자의 게시 양식이 아니라 그래프 파일(`.dyn`)에서 썸네일을 읽어 옵니다.

1. Dynamo에서 그래프를 엽니다.
2. **파일 > 그래프 특성 표시 > 일반**으로 이동합니다.
3. 이미지 필드에 내보낸 PNG 파일을 추가합니다.
4. 그래프를 저장합니다.

그래프가 패키지에 포함되어 제공되는 경우 게시할 때 해당 `.dyn`을 포함하십시오. [패키지 게시하기](../6_custom_nodes_and_packages/6-2_packages/4-publishing.md)를 참조하십시오.

## 홈에서 결과 확인

1. Dynamo 홈을 엽니다.
2. 최근 항목에서 방금 저장한 그래프를 찾습니다.
3. 카드에 제목과 로고가 잘리지 않고 모두 표시되는지 확인합니다.

문자가 잘린 경우 중앙 쪽으로 이동하고 이미지를 다시 내보낸 다음 그래프 특성을 업데이트합니다. 제너레이티브 디자인에 표시되는 모습에만 의존하지 마십시오. 제너레이티브 디자인에서는 정사각형 전체가 표시됩니다.
