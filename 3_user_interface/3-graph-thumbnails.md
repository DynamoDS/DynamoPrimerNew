# Dynamo 首頁的圖表縮圖

Dynamo 首頁會在一個橫式卡片上顯示圖表縮圖。卡片是 16:9。首頁會將影像置中，並裁剪頂部和底部。

「衍生式設計」會以正方形顯示縮圖，因此方形縮圖看起來很完整。但同一個影像在「首頁」中可能就會缺少標題或標誌。

這適用於任何圖表 (`.dyn`)，而不只是套件中的圖表。請在「圖表性質」中設定影像。影像儲存在圖表檔案中。

{% hint style="info" %}
請將標題、標誌和主影像放在中間的**安全區域**。將方形縮圖的頂部和底部只當作背景。
{% endhint %}

## 縮圖樣板

下載樣板，以此為基礎進行設計。深色的中間部分是首頁顯示的內容。頂部和底部淺色的部分在首頁中會被裁掉。「衍生式設計」會顯示完整的正方形。

> 請下載 SVG 樣板在向量應用程式中編輯，或下載 PNG 樣板將圖稿放在影像編輯器中。

## 製作縮圖

1. 在影像編輯器中開啟 SVG 或 PNG 樣板。
2. 將您的圖稿放在樣板中的粉紅色方形上。
3. 將標題、標誌和主影像放在深色的中間部分。
4. 將頂部和底部的淺色部分當作背景顏色或額外圖案。
5. 隱藏或刪除粉紅色導引線，然後匯出**方形** PNG。

使用**方形**影像 (1:1)。首頁一律會以 16:9 的比例顯示深色的中間部分。像素大小不會改變裁剪範圍。如果您從空白檔案而不是從樣板開始，請製作方形影像。縮圖樣板本身為 840 × 840 像素。

## 在圖表中新增縮圖

首頁會讀取圖表檔案 (`.dyn`) 而不是 Package Manager 發佈表單中的縮圖。

1. 在 Dynamo 中開啟圖表。
2. 前往**「檔案」>「展示圖表性質」>「一般」**。
3. 在「影像」欄位中新增匯出的 PNG。
4. 儲存圖表。

如果要以套件形式傳送圖表，請在發佈時包含該 `.dyn`。請參閱[發佈套件](../6_custom_nodes_and_packages/6-2_packages/4-publishing.md)。

## 在首頁中查看結果

1. 開啟 Dynamo 首頁。
2. 在「最近」底下，找出您剛剛儲存的圖表。
3. 確認卡上的標題和標誌都完全可見。

如果文字被切掉，請往中間移動，再次匯出影像，然後更新「圖表性質」。不要單純依賴「衍生式設計」。「衍生式設計」會顯示完整的正方形。
