# Служба облачных вычислений Dynamo



Служба облачных вычислений Dynamo позволяет реализовать в облаке все возможности среды выполнения визуального программирования Dynamo. Графы больше не запускаются на локальном компьютере: служба выполняет их в безопасной среде для облачных вычислений и возвращает результаты.

## Что такое Dynamo

Dynamo — это язык визуального программирования и среда разработки, которые позволяют создавать программы путем соединения узлов в графе. Эти графы запускаются в среде выполнения Dynamo и позволяют вам автоматизировать сложные задачи, создавать геометрию и внедрять интеграцию с другим программным обеспечением.

## Работа службы облачных вычислений

При использовании Dynamo через облачный клиент (например, проигрыватель Dynamo в Forma) файлы графов `.dyn` отправляются в службу вычислений на обработку. Вот какие действия она выполняет:

1. Получает граф и все входные параметры.
2. Обрабатывает граф в изолированной облачной среде.
3. Возвращает результаты в клиентское приложение.

Обработка в облаке позволяет запускать графы Dynamo, не устанавливая эту программу на локальный компьютер, и использовать вычислительные мощности облака для выполнения сложных операций.

## Преимущества службы облачных вычислений Dynamo

Служба облачных вычислений Dynamo предлагает указанные далее возможности.

**Запуск графов без установки ПО на компьютер.** Графы Dynamo можно обрабатывать через веб-приложения, не устанавливая классическое приложение Dynamo на компьютер.

**Совместная работа и общий доступ.** Доступ к графам можно предоставлять другим участникам проектной группы для их запуска через такие веб-интерфейсы, как Forma. Это упрощает внедрение автоматизированных рабочих процессов в организации.

**Эффективность облачных вычислений.** Используйте преимущества облачной инфраструктуры для выполнения ресурсоемких операций, которые на локальных компьютерах могут занять больше времени.

**Стандартизация среды выполнения.** Запуск графов в управляемой облачной среде обеспечивает одинаковую работу кода на разных компьютерах и у разных пользователей.

**Подключение к Forma.** Взаимодействуйте с API Forma через Dynamo. Дополнительные сведения см. в [этой записи нашего блога](https://dynamobim.org/design-to-configuration-your-rules-in-forma-and-revit-via-dynamo-part-1/).

## Основные характеристики

**Обработка в облаке.** Графы запускаются в облаке, а не на локальном компьютере. Вот что это означает.
- Для запуска графов не нужно устанавливать классическое приложение Dynamo.
- Вы получаете доступ к ресурсам для облачных вычислений.
- Все пользователи работают с единой средой выполнения.

**Безопасность.** Служба обрабатывает графы каждого пользователя в изолированных средах, что обеспечивает безопасность и конфиденциальность данных. Графы и данные, принадлежащие вам и другим пользователям, хранятся отдельно.

**Асинхронная обработка.** Графы запускаются асинхронно — клиенты отправляют задачу в систему и затем отслеживают статус ее выполнения. Это позволяет выполнять длительные вычисления без блокировки остального рабочего процесса.

## Доступность службы в настоящее время

В настоящее время получить доступ к службе облачных вычислений можно следующим образом.
- **Открытая бета-версия проигрывателя Dynamo в Forma.** Выгружайте графы Dynamo, запускайте их и предоставляйте к ним доступ непосредственно в веб-интерфейсе Autodesk Forma.
