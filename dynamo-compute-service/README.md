# Dynamo 클라우드 컴퓨팅



Dynamo Cloud Compute는 Dynamo의 시각적 프로그래밍 런타임 기능을 클라우드에서 제공합니다. 이 컴퓨팅 서비스는 로컬 시스템에서 그래프를 실행하는 대신 안전한 클라우드 환경에서 그래프를 실행하고 결과를 반환합니다.

## Dynamo란 무엇입니까?

Dynamo는 그래프에서 노드를 함께 연결하여 프로그램을 작성할 수 있는 시각적 프로그래밍 언어 및 작성 환경입니다. Dynamo 런타임은 이러한 그래프를 실행하여 복잡한 작업을 자동화하고, 형상을 생성하고, 다른 소프트웨어와 통합할 수 있습니다.

## Compute Service 작동 방식

클라우드 기반 클라이언트(예: Forma의 Dynamo Player)를 통해 Dynamo를 사용하는 경우 `.dyn` 그래프 파일이 실행을 위해 계산 서비스로 전송됩니다. 이 서비스는 다음을 수행합니다.

1. 그래프 및 모든 입력 매개변수 수신
2. 격리된 클라우드 환경에서 그래프 실행
3. 결과를 클라이언트 응용프로그램으로 다시 반환

이 클라우드 기반 접근 방식은 Dynamo를 로컬로 설치하지 않고도 Dynamo 그래프를 실행할 수 있으며 복잡한 작업에 클라우드 컴퓨팅 성능을 활용할 수 있습니다.

## Dynamo Cloud Compute를 사용하는 이유

Dynamo Cloud Compute는 다음과 같은 시나리오를 지원합니다.

**데스크톱 설치 없이 그래프 실행**: 컴퓨터에 Dynamo Desktop을 설치하지 않고도 웹 응용프로그램에서 직접 Dynamo 그래프를 실행할 수 있습니다.

**공동 작업 및 공유**: Forma와 같은 웹 인터페이스를 통해 그래프를 실행할 수 있는 팀 구성원과 그래프를 공유하여 조직 전체에 자동화된 워크플로우를 보다 쉽게 배포할 수 있습니다.

**클라우드 컴퓨팅 활용**: 로컬 시스템에서 진행하면 시간이 오래 걸릴 수 있는 컴퓨팅 집약적인 작업에 클라우드 인프라를 활용할 수 있습니다.

**실행 환경 표준화**: 제어된 클라우드 환경에서 그래프를 실행하여 다양한 사용자 및 머신 간에 일관된 동작을 보장합니다.

**Forma에 연결**: Dynamo를 사용하여 Forma API와 상호 작용합니다. [자세한 내용은 이 블로그 게시물을 참조하십시오.](https://dynamobim.org/design-to-configuration-your-rules-in-forma-and-revit-via-dynamo-part-1/)

## 주요 특성

**클라우드 실행**: 그래프가 로컬 시스템이 아닌 클라우드에서 실행됩니다. 이는 다음을 의미합니다.
- 그래프를 실행하기 위해 Dynamo Desktop을 설치할 필요가 없음
- 클라우드 컴퓨팅 리소스에 액세스
- 여러 사용자 간에 일관된 실행 환경 유지

**보안**: 이 서비스는 데이터 보안 및 개인 정보 보호를 보장하기 위해 격리된 환경에서 각 사용자의 그래프를 실행합니다. 사용자 그래프와 데이터는 다른 사용자와는 별도로 보관됩니다.

**비동기 처리**: 그래프 실행은 비동기적으로 발생합니다. 클라이언트는 작업을 제출하고 완료될 때까지 상태를 확인할 수 있습니다. 이렇게 하면 워크플로우를 차단하지 않고 장기 실행 계산을 수행할 수 있습니다.

## 현재 가용성

Dynamo Cloud Compute는 현재 다음을 통해 사용할 수 있습니다.
- **Forma Open Beta의 Dynamo Player**: Autodesk Forma의 웹 인터페이스에서 직접 Dynamo 그래프를 업로드, 공유 및 실행할 수 있습니다.
