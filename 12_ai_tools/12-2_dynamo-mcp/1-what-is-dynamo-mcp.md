# Dynamo MCP 서버란 무엇입니까?

**MCP**는 Model Context Protocol의 약어입니다. AI 모델이 공통 프로토콜을 통해 소프트웨어에 연결할 수 있도록 하는 개방형 표준입니다. MCP 서버는 프로그램의 도구와 데이터를 외부에 제공하므로 AI 클라이언트가 실시간 컨텍스트를 읽고, 작업을 수행하고, 구조화된 결과를 반환할 수 있습니다.

**DynamoMCP**는 Dynamo에 내장된 MCP 서버입니다. Autodesk Assistant를 현재 활성화된 Dynamo 세션에 연결하여 그래프, 노드, 와이어 및 작업공간 상태를 공유합니다. 이를 통해 AI가 사용자가 실제로 작업 중인 내용을 바탕으로 도움을 제공할 수 있습니다.

Dynamo 사용자에게 이는 Assistant가 일반적인 질문에 답하는 것 이상의 기능을 제공함을 의미합니다. Assistant는 열려 있는 그래프를 살펴보고, 노드 관련 문제를 해결하도록 지원하며, 수동으로 복사하여 붙여넣지 않아도 실제 세션의 컨텍스트를 바탕으로 캔버스를 업데이트할 수 있습니다.

DynamoMCP는 Dynamo 4.2.0 이상에서 사용할 수 있습니다.

### DynamoMCP 사용 방법

사용자는 DynamoMCP를 Autodesk Assistant를 통해 사용하며, 별도로 설정하거나 독립형 인터페이스를 사용할 필요가 없습니다. Assistant는 질문을 하고, 그래프에 대한 도움을 받고, AI가 Dynamo의 실시간 컨텍스트를 활용하도록 하는 진입점입니다.

Assistant를 여는 위치는 작업 환경에 따라 다음과 같이 다릅니다.

- **Dynamo Sandbox** — Dynamo 내부의 Autodesk Assistant에서 Dynamo MCP 도구를 사용할 수 있습니다.
- **Revit** — Revit 내부의 Autodesk Assistant에서 Dynamo MCP 도구를 사용할 수 있습니다.

두 환경 모두 현재 세션을 유지한 상태에서 동일한 방식으로 Autodesk Assistant를 사용하여 DynamoMCP에 접근할 수 있습니다.
### DynamoMCP로 할 수 있는 작업

DynamoMCP는 Assistant에 일련의 **도구**를 제공합니다. 각 도구는 캔버스 읽기, 노드 배치, 그래프 실행 등 Dynamo에서 특정 작업 하나를 수행합니다. 이러한 도구를 사용자가 직접 호출할 필요는 없습니다. 원하는 작업을 일상적인 언어로 설명하면 Assistant가 필요한 도구를 선택합니다.

도구의 종류를 알아 두는 것은 여전히 유용합니다. Assistant가 어떤 작업을 수행할 수 있는지 파악할 수 있고, Assistant가 실제로 수행할 수 있는 요청을 작성하는 데도 도움이 됩니다.

{% hint style="info" %}
이름이 `get_`로 시작하는 도구는 세션의 정보만 읽습니다. 그 밖의 모든 도구는 그래프를 변경할 수 있습니다.
{% endhint %}

#### 현재 그래프 읽기

이러한 도구를 사용하면 Assistant가 답변하거나 변경 작업을 수행하기 전에 사용자가 현재 작업 중인 내용을 확인할 수 있습니다.

| 도구 | 기능 |
| --- | --- |
| `get_workspace_info` | 캔버스에 있는 노드, 와이어, 그룹, 메모 및 작업공간 세부 정보를 나열합니다. |
| `get_selection` | 사용자가 선택한 노드, 와이어 및 그룹을 알려 줍니다. |
| `get_node_connections` | 특정 노드가 어떤 항목과 연결되어 있는지 포트별로 보여 줍니다. |
| `get_node_property` | 미리보기, 고정, 고정된 미리보기 및 레이블과 같은 노드 설정을 알려 줍니다. |
| `get_node_lacing` | 노드의 레이싱 설정을 알려 줍니다. |
| `get_installation_info` | Dynamo 버전, 실행 중인 호스트 및 릴리즈 정보 링크를 제공합니다. |

*프롬프트 예시: "지금 내 캔버스에 무엇이 있어?"*

#### 적합한 노드 찾기

Dynamo에는 설치된 패키지의 노드를 포함하여 수천 개의 노드가 있습니다. 이러한 도구를 사용하면 Assistant가 추측하는 대신 적합한 노드를 선택할 수 있습니다.

| 도구 | 기능 |
| --- | --- |
| `get_nodes_info` | 패키지 노드를 포함한 노드 라이브러리를 검색하고, 배치할 정확한 노드를 반환합니다. |
| `get_node_help` | 노드에 대한 도움말 설명을 반환하며, 해당 노드의 예제 그래프가 있는 경우 그 경로도 반환합니다. |
| `get_type_schema` | 점, 숫자, 색상과 같은 Dynamo 유형에 필요한 데이터 형식을 반환합니다. |

*프롬프트 예시: "표면의 면적을 구하려면 어떤 노드를 사용해야 해?"*

#### 그래프 작성 및 편집

이러한 도구는 캔버스에서 작업을 수행합니다.

| 도구 | 기능 |
| --- | --- |
| `create_nodes` | 선택적으로 시작 값을 지정하여 하나 이상의 노드를 캔버스에 배치합니다. |
| `set_node_value` | 숫자, 문자열, 코드 블록 및 드롭다운과 같은 입력 노드의 값을 설정합니다. |
| `connect_nodes` | 출력 포트를 입력 포트에 와이어로 연결합니다. |
| `disconnect_nodes` | 두 노드 사이의 와이어를 제거합니다. |
| `delete_node` | 캔버스에서 노드를 제거합니다. |
| `rename_node` | 입력 노드와 Watch 노드의 이름을 변경하여 용도를 명확하게 표시합니다. 함수 노드의 이름은 원래대로 유지됩니다. |
| `select_nodes` | 캔버스에서 노드를 선택하여 Assistant가 어떤 노드를 가리키는지 확인할 수 있도록 합니다. |
| `set_node_property` | 미리보기, 고정, 고정된 미리보기, 레이블 및 입력 또는 출력과 관련된 노드 설정을 켜거나 끕니다. |
| `set_node_lacing` | 레이싱을 자동, 최단, 최장 또는 외적으로 설정합니다. |
| `set_node_port_list_at_level` | 입력 포트의 리스트 수준을 설정합니다. |

*프롬프트 예시: "숫자 슬라이더를 추가하고 원의 반지름 입력에 와이어로 연결해 줘."*

#### 그래프 구성 및 문서화

작동하는 그래프라고 해서 항상 읽기 쉬운 것은 아닙니다. 이러한 도구를 사용하면 그래프의 레이아웃, 그룹, 색상 및 메모를 관리할 수 있습니다.

| 도구 | 기능 |
| --- | --- |
| `create_group` | 노트 세트를 하나의 그룹으로 묶습니다. |
| `create_groups` | 하나의 단계로 여러 그룹을 만듭니다. |
| `ungroup_by_guid` | 그룹을 제거합니다. 그룹에 포함된 노드는 캔버스에 그대로 남습니다. |
| `ungroup_by_title` | 그룹 제목을 기준으로 그룹을 해제합니다. 그룹에 포함된 노드는 캔버스에 그대로 남습니다. |
| `get_available_group_styles` | 기본 설정에 지정된 사용자 지정 스타일을 포함해 사용할 수 있는 그룹 스타일을 나열합니다. |
| `assign_group_styles` | 입력, 작업, 출력 및 검토 등의 그룹 스타일을 적용합니다. |
| `get_notes` | 그래프에 있는 메모를 나열합니다. |
| `create_notes` | 그래프의 특정 부분을 설명하는 메모를 추가합니다. |
| `update_notes` | 메모의 텍스트를 편집하거나 메모를 이동합니다. |
| `delete_notes` | 메모를 제거합니다. |
| `set_note_state` | 메모를 노드에 고정하여 노드와 함께 이동하도록 하거나 고정을 해제합니다. |
| `auto_layout_workspace` | Dynamo에 내장된 자동 레이아웃 기능을 사용해 노드를 재배치합니다. |
| `set_workspace_description` | 그래프에 대한 설명을 파일의 특성에 기록합니다. |

*프롬프트 예시: "이 그래프를 입력, 작업, 출력별로 그룹화하고 색상으로 구분한 다음, 짧은 메모를 추가해 줘."*

#### 그래프 실행 및 결과 확인

| 도구 | 기능 |
| --- | --- |
| `run_workspace` | 현재 그래프를 실행합니다. 자동 모드에서는 변경 사항이 있을 때마다 그래프가 이미 다시 실행되므로 이 단계는 생략됩니다. |
| `get_workspace_warnings` | 경고 또는 오류가 있는 노드, 메시지 텍스트 및 권장되는 다음 단계를 나열합니다. 이 도구를 사용하려면 먼저 그래프를 실행해야 합니다. |
| `get_node_output_values_shapes` | 특정 노드 또는 그래프의 모든 노드에서 출력되는 값의 요약을 제공합니다. |
| `get_node_output_value` | 요약하기에는 결과가 너무 큰 경우, 단일 노드의 전체 출력을 한 번에 한 페이지씩 읽어 옵니다. |

*프롬프트 예시: "그래프를 실행하고 List.GetItemAtIndex 노드에 경고가 표시되는 이유를 알려 줘."*

#### 그래프 파일 작업

Assistant는 현재 열려 있는 그래프뿐 아니라 디스크에 저장된 그래프에 대한 작업도 수행할 수 있습니다.

| 도구 | 기능 |
| --- | --- |
| `new_workspace` | 비어 있는 새 그래프를 엽니다. 현재 그래프에 저장되지 않은 변경 사항이 있으면 먼저 저장하거나 취소하라는 메시지가 표시됩니다. |
| `save_workspace` | 현재 그래프를 저장합니다. 위치를 지정하지 않으면 문서 폴더의 Dynamo 폴더에 저장됩니다. |
| `edit_graph_from_path` | 저장된 그래프를 실행하지 않고 편집할 수 있도록 엽니다. |
| `insert_graph_from_path` | 저장된 그래프를 현재 캔버스에 병합합니다. 노드 예제 그래프를 가져올 때 이 도구를 사용합니다. |
| `run_graph_from_path` | 사용자가 지정한 입력 값을 선택적으로 적용하여 저장된 그래프를 실행합니다. |
| `run_graph_from_json` | 디스크에 파일로 저장하지 않고 Dynamo JSON 형식으로 제공된 그래프를 실행합니다. |
| `get_graph_info_from_path` | 저장된 그래프를 열지 않고 저장된 그래프의 입력, 출력 및 메타데이터를 읽어 옵니다. |
| `get_graph_info_from_json` | Dynamo JSON 형식으로 제공된 그래프에서 동일한 정보를 읽어 옵니다. |
| `get_graphs_info_from_path` | 그래프가 저장된 폴더를 검색하고 각 그래프에 포함된 내용을 제공합니다. |
| `get_available_graphs_folders` | 그래프가 포함되어 있을 수 있는 폴더 중 Dynamo에서 인식하는 폴더를 나열합니다. |

*프롬프트 예시: "내 Dynamo 그래프 폴더를 살펴보고 벽을 배치하는 그래프가 무엇인지 알려 줘."*

{% hint style="warning" %}
Assistant는 그래프를 변경할 수 있습니다. 대규모 편집을 요청하기 전에 작업 내용을 저장하고, 기존 파일을 덮어써서 저장하기 전에 결과를 검토하십시오.
{% endhint %}
