# Dynamo MCP サーバとは

**MCP** はモデル コンテキスト プロトコルの略です。これは、AI モデルが共通のプロトコルを介してソフトウェアに接続できるようにするオープン スタンダードです。MCP サーバは、プログラムのツールとデータを公開し、AI クライアントがリアルタイムのコンテキストを読み取り、アクションを実行し、構造化された結果を返せるようにします。

**DynamoMCP** は Dynamo の組み込み MCP サーバです。これにより、Autodesk Assistant がアクティブな Dynamo セッション(グラフ、ノード、ワイヤ、ワークスペースの状態)に接続され、AI によるサポートが実際の作業内容に即したものとなります。

つまり、Assistant は Dynamo ユーザに対して、一般的な質問に答える以上の役割を果たします。開いているグラフを調査し、ノードに関する問題のトラブルシューティングをサポートし、手動のコピーと貼り付けの代わりに、実際のセッションのコンテキストに基づいてキャンバスを更新できます。

DynamoMCP は、Dynamo 4.2.0 以降で利用できます。

### DynamoMCP の使用方法

DynamoMCP は Autodesk Assistant を介して使用します。個別のセットアップやスタンドアロンのインタフェースはありません。Assistant は、質問をしたり、グラフに関する支援を受けたり、AI がリアルタイムの Dynamo コンテキストを利用して作業できるようにするための窓口となります。

Assistant を開く場所は、作業環境によって異なります。

- **Dynamo Sandbox**: Dynamo MCP ツールは、Dynamo 内の Autodesk Assistant で使用できます。
- **Revit**: Dynamo MCP ツールは、Revit 内の Autodesk Assistant で使用できます。

どちらの場合も、現在のセッションを維持したまま、同じ Assistant の環境を使用して DynamoMCP にアクセスできます。
### DynamoMCP でできること

DynamoMCP は、Assistant に**ツール** セットを提供します。各ツールは、キャンバスの読み取り、ノードの配置、グラフの実行など、Dynamo で 1 つのジョブを実行します。これらのツールをユーザ自身が呼び出すことはありません。実現したいことを簡単に説明すると、Assistant が必要なツールを選択します。

それでも、ツールについて把握しておくと役に立ちます。ツールを把握しておくことで、Assistant に何ができるのかを理解でき、実行可能な要求を表現するのに役立ちます。

{% hint style="info" %}
`get_` で始まるツール名は、セッションから情報を読み込むことだけを行います。それ以外のすべてのツールは、グラフを変更することができます。
{% endhint %}

#### 現在のグラフを読み取る

以下のツールを使用すると、Assistant は回答したり変更を加える前に、ユーザが行っている作業を確認できます。

| ツール | 処理内容 |
| --- | --- |
| `get_workspace_info` | キャンバス上の内容(ノード、ワイヤ、グループ、注記、およびワークスペースの詳細)を一覧表示します。 |
| `get_selection` | 選択したノード、ワイヤ、およびグループを報告します。 |
| `get_node_connections` | ノードの接続先をポートごとに表示します。 |
| `get_node_property` | プレビュー、フリーズ、ピン固定されたプレビュー、ラベルなどのノード設定を報告します。 |
| `get_node_lacing` | ノードのレーシング設定を報告します。 |
| `get_installation_info` | お使いの Dynamo のバージョン、実行中のホスト、およびリリース ノートへのリンクを報告します。 |

*プロンプトの例: 「現在キャンバス上には何がありますか?」*

#### 適切なノードを見つける

Dynamo には、インストール済みパッケージのノードを含め、数千ものノードがあります。これらのツールにより、Assistant は推測に頼ることなく、適切なノードを選択できます。

| ツール | 処理内容 |
| --- | --- |
| `get_nodes_info` | パッケージ ノードを含めてノード ライブラリを検索し、配置する正確なノードを返します。 |
| `get_node_help` | ノードのヘルプ説明文と、サンプル グラフ(存在する場合)へのパスを返します。 |
| `get_type_schema` | Point、Number、Color など、Dynamo のデータ型に対して想定されるデータ形式を返します。 |

*プロンプトの例: 「サーフェスの面積を取得するには、どのノードを使えばいいですか?」*

#### グラフを作成、編集する

以下のツールは、キャンバス上で操作を実行します。

| ツール | 処理内容 |
| --- | --- |
| `create_nodes` | キャンバスに 1 つまたは複数のノードを配置します(初期値を設定することも可能)。 |
| `set_node_value` | Number、String、Code Block などの入力ノードや、ドロップダウン形式の入力ノードの値を設定します。 |
| `connect_nodes` | 出力ポートを入力ポートに接続します。 |
| `disconnect_nodes` | 2 つのノード間のワイヤを削除します。 |
| `delete_node` | キャンバスからノードを削除します。 |
| `rename_node` | 入力ノードや Watch ノードの名前を変更し、それぞれの用途が明確になるようにします。関数ノードの名前は元のまま維持されます。 |
| `select_nodes` | キャンバス上のノードを選択状態にし、Assistant が指すノードを確認できるようにします。 |
| `set_node_property` | ノード設定(プレビュー、フリーズ、ピン固定されたプレビュー、ラベル、入力または出力など)のオン、オフを切り替えます。 |
| `set_node_lacing` | レーシングを[自動]、[最短]、[最長]、[外積]に設定します。 |
| `set_node_port_list_at_level` | 入力ポートのリスト レベルを設定します。 |

*プロンプトの例: 「数値スライダを追加し、円の半径入力に接続してください。」*

#### グラフを整理してドキュメント化する

作業中のグラフが、必ずしも読みやすいグラフであるとは限りません。以下のツールは、レイアウト、グループ分け、色、注記を管理します。

| ツール | 処理内容 |
| --- | --- |
| `create_group` | 複数のノードをグループとして囲みます。 |
| `create_groups` | 1 回の操作で複数のグループを作成します。 |
| `ungroup_by_guid` | グループを削除します。その中のノードはキャンバスに残ります。 |
| `ungroup_by_title` | タイトルを指定してグループを削除します。その中のノードはキャンバスに残ります。 |
| `get_available_group_styles` | 使用できるグループ スタイルの一覧を表示します(基本設定に登録されているカスタム スタイルを含む)。 |
| `assign_group_styles` | Input、Action、Output、Review などのグループ スタイルを適用します。 |
| `get_notes` | グラフ内の注記を一覧表示します。 |
| `create_notes` | グラフの一部を説明する注記を追加します。 |
| `update_notes` | 注記のテキストを編集、または注記を移動します。 |
| `delete_notes` | 注記を削除します。 |
| `set_note_state` | 注記をノードに固定(一緒に移動できるようにする)、または固定解除します。 |
| `auto_layout_workspace` | Dynamo に組み込まれた自動レイアウト機能を使用し、ノードを再配置します。 |
| `set_workspace_description` | グラフの説明をファイルのプロパティに書き込みます。 |

*プロンプトの例: 「このグラフを入力、アクション、出力ごとにグループ化して色分けし、簡単な注記を追加してください。」*

#### グラフを実行して結果を確認する

| ツール | 処理内容 |
| --- | --- |
| `run_workspace` | 現在のグラフを実行します。自動モードでは、変更のたびにグラフが再実行されるため、この手順はスキップされます。 |
| `get_workspace_warnings` | 警告またはエラーが発生しているノード、メッセージ テキスト、推奨される次のステップを一覧表示します。最初にグラフを実行しておく必要があります。 |
| `get_node_output_values_shapes` | グラフ内の 1 つのノードまたはすべてのノードの出力値を要約します。 |
| `get_node_output_value` | 出力結果が要約できないほど大量である場合、1 つのノードの出力全体を 1 ページずつ読み取ります。 |

*プロンプトの例: 「グラフを実行し、List.GetItemAtIndex ノードで警告が表示される理由を教えてください。」*

#### グラフ ファイルを操作する

Assistant は、開いているグラフだけでなく、ディスク上のグラフも操作できます。

| ツール | 処理内容 |
| --- | --- |
| `new_workspace` | 新しい空のグラフを開きます。現在のグラフに未保存の変更がある場合は、変更を保存するか破棄するかを確認するメッセージがまず表示されます。 |
| `save_workspace` | 現在のファイルを保存します。場所が指定されていない場合は、Documents 内の Dynamo フォルダに保存されます。 |
| `edit_graph_from_path` | 保存済みのグラフを実行せずに、編集用に開きます。 |
| `insert_graph_from_path` | 保存済みのグラフを現在のキャンバスに統合します。ノードのサンプル グラフは、この方法で取り込みます。 |
| `run_graph_from_path` | 保存済みのグラフを、ユーザが指定した任意の入力値を使用して実行します。 |
| `run_graph_from_json` | ディスク上にファイルは使用せず、Dynamo JSON として渡されたグラフを実行します。。 |
| `get_graph_info_from_path` | 保存済みのグラフを開かずに、入力、出力、メタデータを読み取ります。 |
| `get_graph_info_from_json` | 同様の詳細情報を、Dynamo JSON として渡されたグラフから読み取ります。 |
| `get_graphs_info_from_path` | グラフのフォルダをスキャンし、それぞれのグラフの内容を報告します。 |
| `get_available_graphs_folders` | Dynamo が認識しているフォルダのうち、グラフが含まれている可能性のあるものを一覧表示します。 |

*プロンプトの例: 「Dynamo のグラフ フォルダを調べて、壁を配置するグラフを教えてください。」*

{% hint style="warning" %}
Assistant はグラフを変更する場合があります。大幅な編集を依頼する前に作業内容を保存し、既存のファイルに上書き保存する前に結果を確認してください。
{% endhint %}
