# AI Tools

AI-assisted tooling is becoming part of the everyday Dynamo workflow. This section covers the AI tools that ship with or connect to Dynamo, what they can do, and where their limits are.

* **Autodesk Assistant** — a chat-based assistant built into Dynamo (4.2.0 and later) that can read and directly modify nodes on the canvas.
* **Dynamo MCP** — a Model Context Protocol server that lets external AI clients drive Dynamo programmatically.
