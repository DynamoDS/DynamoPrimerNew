# RevitMCP と DynamoMCP

Autodesk Assistant は、MCP サーバから機能を取得します。各サーバから Assistant にツールのセットが提供され、各ツールはそれぞれが属する製品内で単一の役割を担います。

Revit で作業する場合は、そのうちの 2 つのサーバ、**RevitMCP** と **DynamoMCP** が重要となります。これらは競合する選択肢ではなく、どちらか一方を選ぶものでもありません。それぞれ異なるレベルで機能し、Assistant はユーザの要求に適した方を使用します。

### RevitMCP: モデルの直接操作

RevitMCP は、[Revit パブリック MCP サーバ](https://help.autodesk.com/cloudhelp/2027/JPN/Revit-WhatsNew/files/GUID-97697CBF-0E11-484E-96E5-4277E3E8D61F.htm)として提供され、厳選された一連の Revit API 操作を MCP ツールとしてラップします。各ツールは、モデル内で定義されたアクション(要素の検索、パラメータや個数のチェック、パラメータの一括編集、ビューのスナップショットの取得)に対応しています。

ツール セットがすでに対応しているタスクであれば、最短の方法になります。1 つの要求が 1 回の呼び出しとなり、モデルは即座に変更されます。グラフを作成する必要はなく、その後グラフを実行する必要もありません。

### DynamoMCP: 操作を構築するツール

DynamoMCP は 1 つ上のレベルで機能します。DynamoMCP のツールは、モデル作成のアクションを直接実行しません。代わりに、Dynamo グラフを作成します。具体的には、ノードを配置し、それらを接続し、値を設定して、その結果を実行します。ツールの一覧については、「[Dynamo MCP サーバとは](../12-2_dynamo-mcp/1-what-is-dynamo-mcp.md)」を参照してください。

ノードとは何なのかを考えると、これが重要である理由が分かります。Dynamo ライブラリ内の各ノードは、それ自体が、既に記述、テスト、ドキュメント化された 1 つ以上の API 呼び出しです。パッケージ ノードと Python ノードも同じ方法で使用できます。そのため、少数のグラフ作成ツールで Dynamo ライブラリ全体の機能を利用できます。

その結果、DynamoMCP のツールは既存の機能を利用するだけでなく、新しい機能を生成することができます。Assistant は、固定のアクション一覧から実行する代わりに、ノードを組み合わせてユーザが求めるアクションを構築します。実際には、グラフを書き込む MCP ツールは、より多くのツールを作り出すツールのように機能します。

### 実際の違い

たとえば、あるレベルのドア タグ付けを指示するとします。

- RevitMCP で処理する場合、作業はツールを直接呼び出すことで実行され、タグが表示されます。
- DynamoMCP で処理する場合、Assistant は、ドアを収集するノード、指定されたレベルのドアをフィルタするノード、ドア タグを作成するノードを配置したうえで、そのグラフを実行します。

どちらの方法でもドアにタグが付けられます。2 番目の方法ではキャンバス上にグラフも残ります。

| | RevitMCP | DynamoMCP |
| --- | --- | --- |
| ツールが行う処理 | 定義された Revit 操作を実行 | Dynamo グラフを作成して実行 |
| 操作の範囲 | ツール セットに含まれる操作 | パッケージ ノードや Python ノードを含む、ライブラリ内のすべてのノード |
| 得られる成果 | モデルへの変更 | モデルへの変更と、それを行ったグラフ |
| 用途 | 明確に定義された単一のタスク | 検査、調整、再利用、共有するロジック |

### グラフを残す意義

グラフは単なる結果ではなく、作業を記録したものです。一度キャンバス上に配置されれば、次のことが可能になります。

- 内容を確認し、行われた処理を正確に把握できます。
- タスク全体をもう一度指示することなく、値を変更して再度実行できます。
- 保存して次のプロジェクトで実行したり、同僚に引き渡すことができます。
- Dynamo プレーヤへ公開することで、Dynamo を使用していないユーザでも実行できます。

時間がかかるのは最初の要求だけです。それ以降の実行にかかる手間は、ほとんどありません。

{% hint style="info" %}
Dynamo Sandbox では、操作対象となる Revit モデルが存在しないため、Assistant が利用できるのは DynamoMCP のみとなります。Revit では、両方を利用できます。
{% endhint %}

### 指示内容の選び方

プロンプトでサーバ名を指定する必要はありません。得たい結果を説明するだけで十分であり、Assistant が適切なツールを選択します。

グラフが必要な場合は、その旨を指示してください。*「レベル 2 のドアにタグを付けるグラフを作成してください」*のようなプロンプトを使用すると、単にドアにタグ付けするだけでなく、再利用可能なバージョンを作成することが目的であると Assistant に伝わります。
