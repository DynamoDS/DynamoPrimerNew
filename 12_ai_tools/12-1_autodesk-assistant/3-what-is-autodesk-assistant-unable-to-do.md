# Что Autodesk Assistant еще не умеет

### Обновление пакетов

Autodesk Assistant пока не может скачивать и устанавливать пакеты в Dynamo

![](../../.gitbook/assets/Aa_Update.jpg)

Как видно на изображении выше, инструмент Autodesk Assistant не может изменять, устанавливать или удалять внешние пакеты, связанные с Dynamo. Он может предоставить инструкции, как установить их самостоятельно.


### Чтение и запись файлов напрямую

Инструмент Autodesk Assistant работает с файлами графов Dynamo: он может открыть граф, вставить его в рабочую область, запустить граф и сохранить работу. Он не может самостоятельно читать или записывать другие файлы на жестком диске.

В приведенном ниже примере в рабочей области создана геометрия. Пользователь просит Autodesk Assistant взять точки, составляющие геометрию, и экспортировать их в файл JSON. Хотя помощник Autodesk Assistant не может создать этот файл JSON напрямую, он может создать сценарий Dynamo для выполнения этой операции.

![](../../.gitbook/assets/Aa_WriteFileGeom.jpg)

![](../../.gitbook/assets/Aa_WriteFile.jpg)

Это предложение — шаблон, который нужно запомнить. Все, что находится за пределами графа, доступно через узлы, а не через Assistant.

### Изменение модели Revit без использования графа

![](../../.gitbook/assets/Aa_Data_sampleProject.jpg)

Autodesk Assistant для Dynamo не подключается напрямую к модели Revit. Попросите помощника отредактировать модель так, как вы бы попросили Assistant в Revit, и он ответит, что не может.

![](../../.gitbook/assets/Aa_Revit_Limits.jpg)

При этом модель Revit он может изменить. Он делает это следующим образом: размещает узлы Revit, соединяет их вместе, и модель изменяется при запуске графа.

![](../../.gitbook/assets/Aa_viewScript.jpg)

Такой подход подразумевает два аспекта:

- **Пока граф не будет запущен, ничего не изменится.** Сначала можно прочитать граф и скорректировать значения. Модель затрагивается только при запуске графа пользователем либо инструментом Assistant по запросу пользователя.
- **Изменение можно повторить.** Граф остается в рабочей области. Сохраните его, чтобы снова выполнить ту же задачу в другой модели, или предоставьте к нему доступ своей группе.

Если требуется однократное непосредственное редактирование без использования графа, используйте Autodesk Assistant в Revit.
