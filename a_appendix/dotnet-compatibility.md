# Zgodność interfejsu API

W poniższej tabeli przedstawiono wersje platformy .NET przeznaczone dla każdej serii głównych wydań dodatku Dynamo. Jest to istotne podczas kompilowania pakietów lub rozszerzeń, ponieważ projekt musi być przeznaczony dla zgodnej wersji platformy .NET.

| Wersja dodatku Dynamo | Wersja platformy .NET       |
| -------------- | ------------------ |
| 0.9 – 2.0      | .NET Framework 4.5 |
| 2.1 – 2.6      | .NET Framework 4.7 |
| 2.7 – 2.19     | .NET Framework 4.8 |
| 3.0 – 3.6      | .NET 8             |
| 3.3.2          | .NET 10            |
| 3.7            | .NET 10            |
| 4.0+           | .NET 10            |

{% hint style="info" %} 3.3.2 i 3.7 to wydania specjalne z platformą .NET 10 przeniesioną z wersji 4.0 Release Candidate. {% endhint %}

* [Aktualizowanie pakietów dla dodatku Dynamo 3.x / .NET 8](../11\_developer\_primer/3\_developing\_for\_dynamo/6-1-updating-your-packages-and-dynamo-libraries-for-dynamo-3x-Net8.md)
