# Compatibilidad con .NET

En la tabla siguiente, se indica a qué versión de .NET está destinada cada una de las principales series de versiones de Dynamo. Esto es importante a la hora de crear paquetes o extensiones, ya que el proyecto debe estar dirigido a una versión compatible de .NET.

| Versión de Dynamo | Versión de .NET       |
| -------------- | ------------------ |
| 0.9 - 2.0      | .NET Framework 4.5 |
| 2.1 - 2.6      | .NET Framework 4.7 |
| 2.7 % - 2.19     | .NET Framework 4.8 |
| 3.0 - 3.6      | .NET 8             |
| 3.3.2          | .NET 10            |
| 3.7            | .NET 10            |
| 4.0+           | .NET 10            |

{% hint style="info" %} Las versiones 3.3.2 y 3.7 son versiones especiales con .NET 10 adaptadas a partir de la versión candidata 4.0\. {% endhint %}
