# .NET 相容性

下表顯示每個主要 Dynamo 版本系列所針對的 .NET 版本。這在建置套件或延伸時很重要，因為您的專案必須針對相容的 .NET 版本。

| Dynamo 版本 | .NET 版本       |
| -------------- | ------------------ |
| 0.9 – 2.0      | .NET Framework 4.5 |
| 2.1 – 2.6      | .NET Framework 4.7 |
| 2.7 – 2.19     | .NET Framework 4.8 |
| 3.0 – 3.6      | .NET 8             |
| 3.3.2          | .NET 10            |
| 3.7            | .NET 10            |
| 4.0+           | .NET 10            |

{% hint style="info" %} 3.3.2 和 3.7 是從 4.0 候選版本向後移植 .NET 10 的特殊版本。{% endhint %}
