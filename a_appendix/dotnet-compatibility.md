# Compatibilità con .NET

Nella tabella seguente è indicato a quale versione di .NET è destinata ciascuna delle principali serie di release di Dynamo. Questo è importante quando si creano pacchetti o estensioni, poiché il progetto deve essere destinato ad una versione di .NET compatibile.

| Versione di Dynamo | Versione di .NET       |
| -------------- | ------------------ |
| 0.9-2.0      | .NET Framework 4.5 |
| 2.1-2.6      | .NET Framework 4.7 |
| 2.7-2.19     | .NET Framework 4.8 |
| 3.0-3.6      | .NET 8             |
| 3.3.2          | .NET 10            |
| 3,7            | .NET 10            |
| 4.0 e successive           | .NET 10            |

{% hint style="info" %} 3.3.2 e 3.7 sono release speciali con .NET 10 sottoposto a backporting dalla release candidata 4.0\. {% endhint %}

Per indicazioni su come aggiornare i pacchetti ad una nuova versione di .NET, consultare le guide alla migrazione nella Guida introduttiva per sviluppatori:

* [Aggiornamento di pacchetti per Dynamo 2.x](../11\_developer\_primer/3\_developing\_for\_dynamo/6-0-updating-your-packages-and-dynamo-libraries-for-dynamo-2x.md)
* [Aggiornamento di pacchetti per Dynamo 3.x/.NET 8](../11\_developer\_primer/3\_developing\_for\_dynamo/6-1-updating-your-packages-and-dynamo-libraries-for-dynamo-3x-Net8.md)
* [Aggiornamento di pacchetti per Dynamo 4.x/.NET 10](../11\_developer\_primer/3\_developing\_for\_dynamo/6-2-updating-your-packages-and-dynamo-libraries-for-dynamo-4x.md)
