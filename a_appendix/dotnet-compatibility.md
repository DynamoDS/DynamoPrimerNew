# Kompatibilita rozhraní .NET

V následující tabulce jsou uvedeny verze rozhraní .NET, které využívají jednotlivé hlavní verze aplikace Dynamo. Tyto informace jsou důležité při vytváření balíčků nebo rozšíření, protože projekt musí být nastaven na kompatibilní verzi rozhraní .NET.

| Verze aplikace Dynamo | Verze rozhraní .NET       |
| -------------- | ------------------ |
| 0.9–2.0      | Rozhraní .NET 4.5 |
| 2.1–2.6      | Rozhraní .NET 4.7 |
| 2.7–2.19     | Rozhraní .NET 4.8 |
| 3.0–3.6      | Rozhraní .NET 8             |
| 3.3.2          | Rozhraní .NET 10            |
| 3,7            | Rozhraní .NET 10            |
| 4.0+           | Rozhraní .NET 10            |

{% hint style="info" %} Verze 3.3.2 a 3.7 jsou speciální verze s rozhraním .NET 10 zpětně portovaným z kandidátské verze 4.0\. {% endhint %}
