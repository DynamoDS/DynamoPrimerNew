# .NETの互換性

次の表は、Dynamo の各主要リリース シリーズと、対応している .NET のバージョンを示しています。プロジェクトでは互換性のある .NET バージョンをターゲットにする必要があるため、この情報はパッケージや拡張機能をビルドする際に重要です。

| Dynamo のバージョン | .NET のバージョン       |
| -------------- | ------------------ |
| 0.9 ～ 2.0      | .NET Framework 4.5 |
| 2.1 ～ 2.6      | .NET Framework 4.7 |
| 2.7 ～ 2.19     | .NET Framework 4.8 |
| 3.0 ～ 3.6      | .NET 8             |
| 3.3.2          | .NET 10            |
| 3.7            | .NET 10            |
| 4.0+           | .NET 10            |

{% hint style="info" %} 3.3.2 および 3.7 は、.NET 10 が 4.0 リリース候補からバックポートされた特別なリリースです。{% endhint %}

パッケージを新しい .NET バージョンに更新する場合のガイダンスについては、Developer Primer のマイグレーション ガイドを参照してください。
