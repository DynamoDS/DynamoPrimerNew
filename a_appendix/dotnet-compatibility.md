# .NET 兼容性

下表显示了每个主要 Dynamo 版本系列面向的 .NET 版本。这在生成软件包或扩展时是相关的，因为项目必须面向兼容的 .NET 版本。

| Dynamo 版本 | .Net 版本       |
| -------------- | ------------------ |
| 0.9 – 2.0      | .NET Framework 4.5 |
| 2.1 – 2.6      | .NET Framework 4.7 |
| 2.7 – 2.19     | .NET Framework 4.8 |
| 3.0 – 3.6      | .NET 8             |
| 3.3.2          | .NET 10            |
| 3.7            | .NET 10            |
| 4.0+           | .NET 10            |

{% hint style="info" %} 3.3.2 和 3.7 是从 4.0 候选发布版向后移植的 .NET 10 的特殊版本。{% endhint %}
